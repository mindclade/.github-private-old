MINDCLADE — FONTS

The identity uses two typefaces. Both are free and open
source under the SIL Open Font License 1.1, which means you
can install them, ship them on your website, and redistribute
them inside the company at no cost.

------------------------------------------------------------
1. INSTRUMENT SANS — monogram, wordmark, all interface text

   https://fonts.google.com/specimen/Instrument+Sans

   Weights you need: 400, 500, 600, 700
   Monogram: 700 at -7.5% letter-spacing
   Wordmark: 600 at -5% letter-spacing

2. JETBRAINS MONO — code, labels, the mc. sub-mark

   https://fonts.google.com/specimen/JetBrains+Mono

   Weights you need: 400, 500

------------------------------------------------------------
LOCAL FILES IN THIS REPOSITORY

InstrumentSans-Variable.ttf contains the normal-width 400,
500, 600, and 700 weights used by the identity. JetBrains
Mono is stored as separate Regular (400) and Medium (500)
files.

Matching WOFF2 files are the web delivery formats. Keep the
TTF files for desktop installation and source fidelity; do
not serve them to browsers when the WOFF2 files are present.

SOURCES.json records the immutable upstream commits, source
paths, SHA-256 hashes, and license mapping. The two OFL files
next to the fonts are the controlling third-party licenses.

------------------------------------------------------------
TO INSTALL ON YOUR MACHINES

On each Google Fonts page above, click "Get font", then
"Download all". Unzip, select the .ttf files, and install
(double-click on macOS, right-click > Install on Windows).
Do this on every laptop that touches a deck or a document.

------------------------------------------------------------
FOR THE WEBSITE

Serve the complete mindclade-brand-assets directory at
/mindclade-brand-assets/ and paste /web/head-snippet.html
inside the page <head>. The snippet loads /web/fonts.css,
which resolves the WOFF2 files locally from ../fonts/. Only
Instrument Sans is preloaded; JetBrains Mono loads on demand
when a page actually uses the mono family.

No Google Fonts or other third-party runtime request is used.
Keep the font files, SOURCES.json, and both OFL license files
together when redistributing the web bundle.

------------------------------------------------------------
WHY THESE TWO

Instrument Sans has the tight, slightly condensed grotesque
proportions that let MC sit as a solid block rather than two
separate letters, and it holds its shape at 16 px. JetBrains
Mono is a coding face by origin, so mc. looks native in a
terminal instead of like a logo pretending to be code.
